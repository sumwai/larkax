# check-man-pages.sh 判据 4 的白名单：手页里**判断为合法**的「汉字与字母紧贴」。
#
# 格式，一条一行，三栏用 | 隔开（理由里不能出现 |）：
#
#   <页名> | <紧贴片段> | <理由>
#
# 页名是 man/man1 下的文件名（`larkaxctl-wallet.1`），片段是屏幕上紧贴的那两个
# 字（汉字在前或字母在前，各取一个），必须与命中处逐字相同——扫描器命中的就是
# 这两个字，不是整行。同一页里同一个片段出现几次都只算一条。
#
# 只许减不许增：条目数由 check-man-pages.sh 里的 MAX_ALLOW_ENTRIES 守着。关掉
# 一处之后把它删掉、并把那个数往下调；新增一条要同时改两个文件，而那是会被
# review 看到的 diff。
#
# 条目不再命中时脚本只提示、不失败：那说明紧贴的写法被改掉了，删掉这一行即可。

# `<单id>` 是一个占位符，整个名字读作「单 id」，中间不加空格是它的写法本身；
# 换成 `<单 id>` 会改掉文档里给读者看的占位符形状。
larkaxctl-wallet.1 | 单i | <单id> 是占位符本身，中间不加空格；见 docs/cli-reference.md 的 payout 分录
